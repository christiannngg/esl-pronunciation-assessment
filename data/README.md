# Data

This directory holds all project datasets. **Raw data is not committed to
git** (see `.gitignore`) — this file documents how to obtain it.

- `raw/` — original, unmodified datasets as downloaded
- `processed/` — cleaned/aligned/split data ready for model input
- `external/` — any auxiliary data (e.g. pretrained alignment models)
